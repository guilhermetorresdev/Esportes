# Versão 1.8

## Resumo

- Consolidação das adaptações React do portal, incluindo inscrição, administrativo, agenda, arquivos, Almoxarifado, presença, frequência, uploads, Capi e descanso.
- Persistência e APIs do Almoxarifado, agenda compartilhada, validação da ficha de inscrição e proteção CSRF.
- Atualização de documentação, rotas, operação de produção, scripts de backup/restauração e testes de fumaça.
- Inclusão da documentação e do script SQL do cadastro auxiliar de núcleos.

## Verificação

- `npm run test:accessibility` em `frontend`: 12 testes aprovados.
- `npm run build` em `frontend`: concluído com sucesso.
- `backend/mvnw.cmd test` em `backend`: 87 testes aprovados, nenhuma falha.
- A consulta de tags remotas não foi possível por indisponibilidade de rede; a série local conferida chegava até `v1.5`.
